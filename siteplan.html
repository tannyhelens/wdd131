Santos Tech Studio

Website Planning Document

Site Name

Santos Tech Studio

I chose this name because it represents a professional technology and web development studio. The website will showcase my web development projects, technical skills, and contact information for potential employers and clients. The name is simple, professional, and easy to remember.

Optional domain: santostechstudio.com

Site Purpose

The purpose of this site is to present my web development projects, describe my skills, and provide a way for visitors or future employers to contact me. The site will include a home page, project examples, and a contact form.

Scenarios

  • What kind of web projects has Tanny created?
  • How can I contact Tanny for more information?
  • What skills does Tanny have in web design and development?

Color Schema

Navy Blue: Used for headings, header, and footer.

Light Beige: Used for the page background.

Coral: Used for buttons, links, and accent details.

Typography

Arial: Used for headings.

Arial: Used for paragraphs and general text.
